# Security

## Секреты

В репозитории **нет реальных секретов**:
- `.env`, `.env.production`, `deploy.env` — в `.gitignore`.
- Для bootstrap используйте `*.env.example` и `deploy.env.example`.
- Реальные креды (WP admin, Beget SSH, YooKassa Secret Key, DB, JWT, SMTP, Dolphin API key)
  хранятся в парольном менеджере команды.

## Сообщить об уязвимости

Обнаружили утечку ключа или уязвимость — напишите владельцу приватно, **не открывая публичный issue**.

## Если что-то попало в историю git

Если в commit случайно попал пароль или ключ:
1. Немедленно смените скомпрометированное значение (WP-админ, YooKassa, SSH-ключ и т.п.).
2. Удалите из истории через `git filter-repo` и force-push (осторожно — переписывает историю).
3. Поставьте вопрос о ротации на внутренний обзор безопасности.

## Защита admin-доступа

- `/wp-login.php` заблокирован на уровне `.htaccess` (403).
- Реальный URL логина скрыт плагином **WPS Hide Login** и не публикуется.
- В репозитории используется плейсхолдер `HIDDEN_LOGIN_SLUG` в `.htaccess` — замените при деплое.
- Включён Wordfence для защиты от брутфорса.
